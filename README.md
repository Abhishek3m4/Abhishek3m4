### 🧠 FPGA Image Reconstruction & Deduplication Engine

**First Prize — Unplugged Hardware Hackathon 2026**

\<p align="center">
\<img src="[https://img.shields.io/badge/Verilog%20HDL-FF6F00?style=flat-square](https://img.shields.io/badge/Verilog%20HDL-FF6F00?style=flat-square)"/>
\<img src="[https://img.shields.io/badge/Artix--7-6A1B9A?style=flat-square](https://img.shields.io/badge/Artix--7-6A1B9A?style=flat-square)"/>
\<img src="[https://img.shields.io/badge/RTL%20Design-37474F?style=flat-square](https://img.shields.io/badge/RTL%20Design-37474F?style=flat-square)"/>
\<img src="[https://img.shields.io/badge/100%20MHz-009688?style=flat-square](https://img.shields.io/badge/100%20MHz-009688?style=flat-square)"/>
\</p>

Built a pipelined **8-bit grayscale image-processing chain** using:

`Median Filter → Gaussian Filter → Bilateral Filter → Spatial Kalman Filter → aHash → Hamming Distance`

### Results

```text
PSNR Gain       ≈ 10 dB
SSIM            ≈ 0.93
Pipeline        1 pixel / clock
Target          100 MHz
Throughput      ≈ 100 Mpixel/s
```
